# 开发路线

2026-10-23 确认八类：杯子、瓶子、书、橡皮、螺丝刀、螺丝、螺母、垫圈。用户选择五金零件，不包含电子零件。

每阶段先实现、检查，随后提交并推送；停下来向用户解释成果、知识、通俗类比、验证方式与限制，等待用户继续。阶段内的独立修正也按实际内容提交，不为凑数量拆分。

| 阶段 | 交付与完成条件 | 知识与通俗理解 |
|---|---|---|
| 1 需求、仓库与环境 | 范围、类别、标注、验收、依赖、本机配置和检查落地；保留远程历史 | 配置与版本管理；整理图纸、工具和施工记录 |
| 2 YOLOv8 预训练基线 | 原图读取、框、类别、分数、计数及无结果处理；保存基线；新五类显示尚未训练 | 坐标、推理、阈值；先看看模型原来会什么 |
| 3 数据集准备（进行中） | 已完成来源筛选、转换、120 个五金框修正和第二轮叠加检查；草稿增至 64 张，多类及桌面场景仍少。补样并复核后才完成阶段 | 数据质量与泄漏；先编题，还要检查题目答案并补足题量 |
| 4 YOLOv8 微调（三轮试跑完成，效果未验收） | 已固定 YOLOv8n、640、batch 4、3 轮试跑、GPU 0；默认关闭 AMP 和内存缓存。当前 64 张样本经范围批准，在可见 PowerShell 完成三轮并保存权重和逐类验证；默认阈值样例漏检，需补数据后继续训练 | 迁移学习、过拟合、精确率、召回率、mAP；先检查训练链路，再用独立试卷 |
| 5 SAM 2 分割 | 自主串联检测框与 SAM 2；保持原图坐标；检测分数与掩膜质量分开；处理空结果 | 提示分割和模块接口；先画框再描边 |
| 6 视觉大模型 | 此时提醒用户选择服务并本地配置密钥；独立原图输入、结构化输出、校验及失败处理 | 图文 API、提示词、JSON；另一位解题者独立交卷 |
| 7 对比界面 | Gradio 上传一次，展示两路结果、耗时、数量差异和错误状态 | 事件、状态和资源；把零件装成可操作的机器 |
| 8 实验与验收 | 固定测试组、复现说明、项目介绍、真实个人感悟、录屏与验收核查 | 公平比较与技术表达；展示成品也解释证据 |

## 数据规模与训练门槛

之前针对三类提出的 200～400 张不是八类训练的固定预算。八类包含密集小零件，应逐类统计图片、实例、验证和测试覆盖，再决定首轮规模。不以大量近似图替代场景多样性，不保证固定张数一定够用。

第 3 阶段交付真实数据清单，列明每类缺口和采用来源。类别定义一致、标签可检查、独立划分可用后，才进入训练。公开数据不足时明确剩余拍摄或补标工作，不用其他类别充数。

小零件重点观察缩放后的像素尺寸、密集摆放和金属反光。当前透明袋五金图在 640 尺寸下的标注短边不低于 16 像素，但这些照片仍是单一背景。首轮先做可见的小批次试跑，再依据验证集决定补拍、输入尺寸或切片方案，不提前安装整套扩展工具。

## 学习如何落地

- 第 2～5 阶段结合实现解释 OpenCV、YOLO 类别／分数／框、SAM 点框提示与掩膜。
- 第 6 阶段结合图文请求学习 token、embedding、attention、位置编码、编码器／解码器和多模态输入。
- 概念讲解不伪装成自行实现 Transformer，不把模型描述当成校准过的概率。

## 训练可见与密钥时机

任何训练，包括之后的试跑，执行前都打开项目终端供用户查看，展示命令和实时输出。日志和权重留在忽略的运行目录；配置与结果摘要入库。第 1 阶段不运行旧的一轮训练自检。

第 6 阶段才提醒用户配置服务、模型名和密钥。密钥写入本机忽略的配置文件，不要求用户写进公开对话。调用前说明图片发送到所选服务。
