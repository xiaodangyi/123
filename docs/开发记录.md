## 第 2 阶段：YOLOv8 预训练检测基线

日期：2026-10-23（Asia/Shanghai）。

### 实际工作

- 自主编写 deskvision 模块：类别与权重读取、中文路径图片解码、预训练检测、原图坐标整理、八类状态、中文绘图与命令行导出。
- 复用本机 YOLOv8n 权重，自动使用可用 GPU，也能显式选择 CPU。权重缺失直接报错，禁止自动下载；不新建环境，不训练。
- 每次保存独立 PNG 和 JSON，记录输入、权重、类别配置哈希、设备、参数、版本和单次耗时。
- 空检测正常返回；未训练类别保持 null；文件或模型失败退出非零，不伪造零计数。
- 用已有 COCO128 样例和纯白图验证功能，发现同一罐子同时被分为杯子与瓶子，改为跨类别重复框抑制并复测；保留前后记录。牛奶盒误识别和类别范围差异如实记录。
- 显式声明业务直接使用的 NumPy 与 Pillow，新增中文使用说明及关键语义检查。

### 验证与限制

关键语义五项测试通过；不存在图片、损坏图片、非法阈值、非法尺寸与缺失权重五项命令行失败路径按预期退出。已有 GPU 样例可生成结果，CPU 纯白图可生成正常空检测；中文标注已实际查看。配置、依赖和补丁检查在提交前复核。

样例不等于独立测试集，首次调用耗时不等于稳定帧率。跨类别抑制降低重复计数，但不能修复错误分类，也可能压掉高度重叠的不同物体。新增五类未训练，尚未完成八类验收。

### 讲解提纲

- YOLO 先在内部缩放图上预测，再还原为原图框；显示面板不改变坐标。
- 分数阈值像筛选门槛，门槛升高可能同时减少误报、增加漏报。
- 重复框抑制像核对名册，同一物品不能换个类别再数一次。
- JSON 是后续分割和对比模块共用的结构化记录；成功执行不等于识别正确。

完成推送后停在此阶段；下一步为八类数据集准备。
